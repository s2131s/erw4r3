## 💾 PDF DÖNÜŞTÜRME TALİMATLARI

### **Markdown'ı PDF'e Çevirme:**

**Yöntem 1: Pandoc (Önerilen)**
```bash
# Tek dosya
pandoc input.md -o output.pdf \
  --pdf-engine=xelatex \
  -V geometry:margin=1in \
  -V fontsize=11pt \
  -V lang=tr

# Tüm klasör
for file in pdf_research/**/*.md; do
  pandoc "$file" -o "${file%.md}.pdf" \
    --pdf-engine=xelatex \
    -V geometry:margin=1in \
    -V fontsize=11pt \
    -V lang=tr
done
```

**Yöntem 2: VS Code Extension**
